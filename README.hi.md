# dsh-miniapp

DeepSeek Harness के लिए MiniApps — AI द्वारा बनाए गए, स्वयं-निहित एकल-फ़ाइल वेब टूल, जिन्हें एक बार प्रकाशित करें और हमेशा दोबारा इस्तेमाल करें।

एक mini-app **एक ही स्वयं-निहित HTML फ़ाइल** होती है (CSS और JavaScript इनलाइन, तीसरे पक्ष की लाइब्रेरी CDN से)। एजेंट उसे लिखता है, आप एक बार «प्रकाशित करें» दबाते हैं, और उसके बाद वह DSH में कहीं भी खोलने योग्य टूल बन जाती है।

यह [NomiFun Desktop](https://github.com/nomifun/nomifun-desktop) की «MiniApps» सुविधा (v3 unified conversations) से **पोर्ट** किया गया है, पुनर्निर्माण नहीं: उत्पाद चक्र वही है, कार्यान्वयन DSH के प्लगइन अनुबंधों के अनुसार है।

## Compatibility

| Surface | Status |
|---|---|
| Harness | DeepSeek Harness `0.1.2-rc.1` |
| Node | `^22.19.0 \|\| >=24.0.0` |
| Platforms | सभी (शुद्ध ESM; कोई नेटिव कोड नहीं, लोड होते समय कोई नेटवर्क नहीं) |
| Client half | Web UI (`dsh web`), DSH Desktop सहित |

## What it does

यह दस मॉडल-दृश्य टूल और एक क्लाइंट पैनल रजिस्टर करता है:

- **टूल** — `miniapp_create`, `miniapp_list`, `miniapp_get`, `miniapp_iterate`, `miniapp_read_source`, `miniapp_write_source`, `miniapp_publish`, `miniapp_delete`, `miniapp_validate`, `miniapp_import`.
- **पैनल** — पूर्ण-स्क्रीन लाइब्रेरी और रनर, जो साइडबार की सेटिंग्स पंक्ति के दाएँ सिरे वाले आइकन से खुलता है।
- **कंपोज़र मोड** — खाली सेशन पर एक `小程序` चिप और एक टेम्पलेट पैनल (5 इरादा श्रेणियों में 12 टेम्पलेट, हर एक की असली सैंडबॉक्स प्रीव्यू)। टेम्पलेट चुनने पर इनपुट बॉक्स में एक संपादन-योग्य वाक्य लिखा जाता है; `直接创建` मॉडल से गुज़रे बिना टेम्पलेट के मूल कोड से ही एक बना देता है।
- **ऐप चलाने के पाँच स्थान** — पूर्ण-स्क्रीन पैनल, ब्राउज़र टैब, वर्तमान सेशन का टैब (`对话` / `轨迹` के बगल में), दाईं ओर का ड्रॉअर, और बातचीत क्षेत्र के ऊपरी-दाएँ कोने पर टिकी एक तैरती विंडो। सब एक ही सैंडबॉक्स रनर दोबारा इस्तेमाल करते हैं।

भंडारण दो परतों में है और वे भौतिक रूप से अलग रखी जाती हैं: एजेंट जिस कार्य-प्रति को संपादित करता है, और वह प्रकाशित स्नैपशॉट जिसे रनर परोसता है। प्रकाशित करने तक बदलाव लाइव नहीं होते।

मॉडल को दिखने वाला असर: हर टूल कॉल और परिणाम दर्ज होता है, इसलिए पूरा प्रवाह सेशन लॉग से फिर से बनाया जा सकता है। प्रकाशित दस्तावेज़ `/plugins/dsh-miniapp/serve/{id}` पर एक क्षमता-URL से परोसा जाता है और iframe सैंडबॉक्स में रहता है (`allow-same-origin` के बिना)।

## Install

```sh
cd dsh-miniapp
pnpm pack
dsh plugin --profile web add ./dsh-miniapp-0.2.0.tgz
```

इंस्टॉल के बाद DSH को **पुनः आरंभ करें** — bundle परत के बदलाव पुनः आरंभ पर लागू होते हैं। इसके बाद MiniApp आइकन साइडबार की सेटिंग्स पंक्ति के दाएँ सिरे पर दिखता है।

हटाने के लिए:

```sh
dsh plugin --profile web remove dsh-miniapp
```

## Configuration

| Key | Type | Default | Description |
|---|---|---|---|
| `dataDir` | string | `{DSH_HOME}/miniapp` | इंडेक्स, कार्य-प्रतियाँ और प्रकाशित स्नैपशॉट कहाँ रहते हैं |
| `showSidebarEntry` | boolean | `true` | साइडबार प्रविष्टि इंजेक्ट की जाए या नहीं |
| `watchdogMs` | number | `6000` | रनर द्वारा iframe को अटका हुआ घोषित करने से पहले की छूट (मिलीसेकंड) |

कॉन्फ़िगरेशन `lib/index.js` में Schemastery `Config` schema द्वारा सत्यापित होता है; कोई भी समायोज्य पैरामीटर हार्डकोड नहीं है। `cordis.patch.yml` में किसी कुंजी को ओवरराइड करें:

```yaml
- id: dsh-miniapp
  config:
    watchdogMs: 10000
```

## Development

```sh
pnpm test                       # 105 टेस्ट: भंडारण, होस्ट रूट, क्लाइंट अनुबंध
pnpm pack                       # इंस्टॉल करने योग्य tarball बनाएँ
```

सत्यापन परतों में है — मुख्य लॉजिक, होस्ट एकीकरण और क्लाइंट अनुबंध (सभी `node --test`), साथ में एक अस्थायी profile पर असली प्रोसेस में चलाया गया। आर्किटेक्चर, इस प्लगइन को जिन DSH अनुबंधों के इर्द-गिर्द काम करना पड़ा, और पूरा सत्यापन रिकॉर्ड [`docs/design.zh-CN.md`](docs/design.zh-CN.md) में हैं।
